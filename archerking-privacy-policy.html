계정 및 관련 데이터 삭제 요청 안내 바로가기

1. 적용 범위와 버전 구분

이 방침은 궁왕 키우기의 로컬 저장과 Google Play Games·Microsoft PlayFab 연동에 적용됩니다. 실제 이용 가능한 기능은 설치한 앱 버전과 제공 환경에 따라 다릅니다. 이 페이지의 변경만으로 새 앱 버전의 출시나 모든 기기에서의 동작 검증이 완료되었다는 뜻은 아닙니다.

기존 Android 1.0(버전 코드 2)은 로그인과 서버 저장을 사용하지 않는 로컬 저장 버전입니다. 2026년 11월 16일 내부 테스트 Android 1.1(버전 코드 7)에는 Google Play Games 로그인과 기존 개발자 테스트 서버 인증 경로가 포함되었습니다. 아래의 PlayFab 저장·우편·쿠폰 설명은 해당 연동이 포함된 버전에서 적용되며, 이전 로컬 전용 버전에 같은 수집이 있었다는 뜻은 아닙니다.

2. 기기에 저장되는 정보

게임 진행 상황, 재화, 레벨, 장비, 스킬, 스테이지, 유물, 보상 기록 및 설정을 기기의 앱 저장 공간에 저장합니다. 계정 연동 버전은 계정별 저장 구분값, 마지막 서버 저장 기준, 저장 처리 중인 요청과 복구용 데이터도 보관할 수 있습니다. 계정 변경은 기존 계정의 로컬 파일을 자동 삭제하는 동작이 아닙니다.

저장 파일의 무결성 확인값이나 계정 경로의 해시는 파일 암호화 또는 개인정보의 완전한 익명화를 의미하지 않습니다. 기기 내 백업·복구 사본이 남을 수 있습니다.

3. Google Play Games 로그인과 PlayFab 서버 처리

로그인 및 게임 계정

Google Play Games로 사용자를 인증하고, 일회용 서버 인증 코드를 Microsoft PlayFab으로 보내 게임 계정에 로그인합니다. 해당 로그인 설정이 활성화된 버전에서는 연결된 게임 계정이 없으면 PlayFab 게임 계정이 생성될 수 있습니다. Google Play Games 플레이어 식별정보, PlayFab 계정·엔터티 식별정보와 로그인 세션 정보는 계정 구분, 인증, 다른 계정 데이터의 혼입 방지에 사용됩니다. Google 계정 자체와 PlayFab 게임 계정은 구분됩니다.

게임은 Google 계정 비밀번호를 직접 입력받지 않습니다. 로그인 인증 코드와 세션 토큰을 문의 이메일로 보내 달라고 요청하지 않습니다. 게임 진행 저장을 위해 이메일 주소를 입력받는 방식은 사용하지 않습니다. Google과 PlayFab 서비스 자체의 인증·접속 처리는 각 제공자의 정책 및 서비스 설정에도 따릅니다.

게임 저장·복원

PlayFab 연동 버전에서는 계정에 연결된 게임 진행 데이터와 저장 시각·버전·무결성 확인값·요청 식별값 등을 PlayFab 서버로 전송하여 저장 및 복원, 저장 충돌 확인과 재시도에 사용합니다. 진행 데이터에는 재화, 성장, 장비, 스킬, 스테이지, 유물과 보상 관련 기록 등이 포함됩니다. 현재 연결된 경로는 PlayFab 서버 저장이며, Google Saved Games에 이용자가 저장본을 올리고 목록에서 선택해 복원하는 방식이 아닙니다.

로컬 저장과 서버 저장의 완료 시점은 다를 수 있습니다. 연결 실패, 저장 충돌 또는 처리 중인 요청이 있으면 서버에 반영되지 않은 진행이 기기에 남을 수 있습니다. 로그인 성공이나 앱 종료만으로 모든 진행의 서버 저장을 보장하지 않습니다.

우편과 쿠폰

우편 목록 확인·보상 수령, 쿠폰 등록 시 계정 식별정보, 우편 또는 쿠폰 식별정보, 처리 요청 식별값, 보상 내용, 수령·사용 여부 및 처리 결과를 PlayFab에서 처리합니다. 보상의 계정 귀속, 지급, 중복 수령 방지와 오류 복구에 사용하며 관련 기록은 계정의 서버 저장과 함께 보관됩니다. 여기서 우편은 게임 안의 보상 우편이며, 이용자의 개인 이메일함을 읽는 기능이 아닙니다.

수집 최소화와 준비 중인 기능

확인한 현재 모바일 로그인 코드에서는 PlayFab SDK의 기기 정보 보고와 포커스 시간 수집을 끄고, 해당 저장·보상 CloudScript 호출의 PlayStream 이벤트 생성을 끕니다. 이것이 서비스 제공자의 모든 접속·보안 기록이 없다는 뜻은 아닙니다. 광고·별도 공개 랭킹 등 준비 중인 기능의 코드 존재만으로 실제 수집 중이라고 보지 않으며, 실제 활성화 시 처리 항목과 목적을 다시 안내합니다.

과거 개발자 테스트 서버

과거 테스트 서버 인증을 사용한 버전은 Google Play Games 플레이어 ID와 일회용 인증 코드를 HTTPS로 개발자 서버에 전송하고, 계정·로그인 세션의 식별정보, 횟수·시각·환경·만료·활성 상태를 처리했습니다. PlayFab 연동으로 변경했다고 이전 테스트 서버의 기록이 자동 삭제되지는 않습니다. 이전에 Google Saved Games 저장본을 만든 경우에도 해당 서비스의 데이터는 별도로 구분합니다.

4. 계정 및 관련 데이터 삭제 요청

궁왕 키우기(JinguStudio)의 계정 및 관련 데이터 삭제는 jingustudio@gmail.com으로 요청할 수 있습니다. 제목은 “궁왕 키우기 계정 삭제 요청”, 내용에는 대상 게임과 계정 및 관련 데이터의 삭제를 원한다는 의사를 적어 주세요. 앱 재설치 없이도 요청을 접수할 수 있습니다.

해당 안내가 포함된 앱에서는 옵션 → 계정 삭제 요청 → 이메일 작성 또는 처리 안내로 이동할 수 있습니다. 이메일 작성 버튼은 메일 앱만 열며 자동 전송하지 않습니다. 안내 화면이 없는 이전 버전이나 메일 앱을 사용할 수 없는 경우 위 주소로 직접 보내 주세요.

  1. 요청을 접수한 뒤 본인과 대상 계정을 확인하는 방법을 안내합니다. 이메일 발신 주소, 닉네임, 공개 ID 또는 화면 캡처만으로 소유를 확정하지 않습니다.
  2. 확인된 계정의 PlayFab 게임 계정·저장 데이터·우편 및 쿠폰 수령 기록 등 연결된 데이터와, 해당하는 경우 과거 개발자 서버 기록을 구분하여 처리 범위를 안내합니다.
  3. 삭제 처리 후 확인된 결과와 별도 보관 또는 추가 처리가 필요한 범위를 안내합니다. 본인 확인이나 대상 확인이 부족하면 필요한 추가 확인 사항을 안내합니다.

비밀번호, 일회용 로그인 인증 코드, 세션 토큰, 결제카드 정보는 보내지 마세요. Google 계정 전체의 삭제를 요구하지 않습니다. 다른 게임에 연결된 계정까지 영향을 줄 수 있는 삭제는 범위를 확인하지 않은 채 처리하지 않습니다.

이 경로는 지원 담당자에게 삭제를 요청하는 경로이며 자동·즉시 탈퇴 기능이 아닙니다. 페이지를 열거나 이메일 작성 링크를 누르는 것만으로 요청 접수나 삭제가 완료되지 않습니다. 기존 개발자 테스트 서버용 요청번호는 PlayFab 계정 소유 확인이나 삭제 완료 증빙을 대신하지 않습니다.

5. 보관과 삭제 범위

계정에 연결된 게임 저장 및 보상 처리 기록은 서비스 제공, 저장 복구와 중복 지급 방지를 위해 서버에 보관됩니다. 로그아웃, 세션 만료, 계정 전환 또는 앱 제거가 원격 계정 및 관련 기록의 자동 삭제를 의미하지 않습니다. 삭제 요청을 처리할 때는 계정 데이터뿐 아니라 관련 저장·처리 기록과 복구 사본의 범위를 확인합니다.

PlayFab 데이터의 일률적인 자동 삭제 기간이나 모든 사본의 즉시 삭제를 보장하지 않습니다. 서비스 제공자의 삭제 절차에 따라 처리 완료 시점이 달라질 수 있습니다. 별도 보관이 필요한 항목이 있으면 그 항목, 이유와 보관 기간을 확인하여 안내하며, 확인되지 않은 기간을 임의로 약속하지 않습니다.

2026년 11월 16일 확인한 과거 개발자 테스트 환경의 Cloud Logging 기본 로그 버킷은 30일, 필수 감사 로그 버킷은 400일 보관 설정이었습니다. 이는 해당 로그 버킷에 관한 과거 확인값이며 PlayFab이나 모든 계정·게임 데이터의 보관 기간이 아닙니다.

기기 로컬 데이터는 Android 설정의 궁왕 키우기 → 저장 공간 → 앱 데이터 삭제로 제거할 수 있습니다. 메뉴명은 기기마다 다를 수 있고 진행 상황을 잃을 수 있습니다. 로컬 삭제와 PlayFab 서버 삭제, Google 서비스 데이터 삭제, 기기·운영체제 백업 삭제는 별개입니다. 원격 삭제 후 남아 있는 다른 기기의 저장·복구 사본 처리도 지원 문의에서 확인해 주세요.

Google Play Games의 데이터 삭제는 Google의 게임 데이터 삭제 안내를 참고하세요. 이 작업만으로 PlayFab 저장, 과거 개발자 서버 기록이나 지원 이메일이 모두 삭제되는 것은 아닙니다.

6. 외부 서비스 및 문의

  • Google: Google Play 및 Play Games 설치·인증 관련 처리. Google 개인정보처리방침
  • Microsoft PlayFab: 게임 계정 인증, 서버 저장·복원, 우편·쿠폰 처리. Microsoft 개인정보처리방침

이용자가 이메일로 문의하면 보내는 이메일 주소, 문의 내용 및 첨부파일이 지원 연락처로 전달되어 문의와 삭제 요청 처리에 사용됩니다. 게임이 개인 이메일함을 조회하거나 문의 메일을 자동 전송하는 것은 아닙니다. 문의에 불필요한 개인정보와 비밀정보는 포함하지 마세요.

7. 변경 안내

기능 및 정보 처리 방식이 달라지면 이 페이지와 최근 수정일을 갱신합니다. 이번 수정은 PlayFab 저장·우편·쿠폰과 관련 데이터 삭제 요청 범위를 반영하고, Google Saved Games 중심의 이전 설명을 현재 연결 방식과 구분하기 위한 것입니다.
